## Translation review limits

For the original four-language package, translation and independent author-separated review are AI-assisted. No fluent-human certification, journal acceptance, fresh product execution or new empirical validation is claimed. Review checks translation completeness, technical qualifications and retained source bindings; it does not extend the manuscript's underlying evidence scope.

The Hebrew edition uses explicit right-to-left prose direction and left-to-right technical blocks. No browser-specific visual certification is claimed. Readers can use the raw UTF-8 source if their renderer handles mixed-direction mathematics differently.

`TRANSLATION_MANIFEST.json` binds the source and translated files. `TRANSLATION_REVIEW.json` records review scope, corrections and limitations. This package leaves the English source and companion files unchanged.
