## Translation and review

The original five translations were prepared with AI assistance and received separate whole-text language and technical fidelity reviews against the frozen English source. Review findings and edition-status wording were resolved, and the final bytes were checked. Source bindings, section anchors, all 86 registry rows, mathematical blocks and link destinations were also checked.

This was not fluent-human or professional translation certification. No screen-reader or actual-user accessibility certification is claimed. Hebrew uses explicit right-to-left document direction and left-to-right mathematical blocks; markup structure is checked separately from language fidelity. Browser rendering is not certified. Repository links and fragments were checked against authenticated source snapshots; primary external URLs were preserved rather than newly fact-checked. Translation review does not qualify runtime behavior or validate the underlying research.

To suggest a correction, identify the language, stable section or registry ID, and the corresponding English and translated passages. The [existing contribution guide](../../contribute/CONTRIBUTION_CHANNELS.en.md) describes the available discussion route and its CI implications. Specify R6 when discussing these translations; the preserved invitation itself remains bound to its earlier source edition.
